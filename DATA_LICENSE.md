# Licences: code and data are not the same

The code in this repository is MIT (see [`LICENSE`](LICENSE)). **The data under
`runs/` is not.** It is derived from ChEMBL, which is share-alike, so
redistributing those files carries an obligation the MIT licence does not.

This file exists because the distinction is easy to miss: a repository with one
`LICENSE` file reads as uniformly licensed, and `runs/` is committed here
deliberately — on a local machine the log is the only record of a measurement —
so the derived data ships with the code.

## Code — MIT

Everything under `chemdisco/`, `scripts/` and `tests/`. See `LICENSE`.

## Derived data under `runs/` — CC BY-SA 3.0

The committed run artefacts (`discover_shard_0.json`, `shortlist.json`,
`crossdocking.json`, `enrichment.log`, and the rest) contain quantities computed
from ChEMBL bioactivity records: curated compound structures, pIC50 values
derived from ChEMBL activities, docking scores and ligand efficiencies computed
for ChEMBL-derived structures, and candidate SMILES generated by recombining
fragments of ChEMBL compounds.

**ChEMBL is licensed CC BY-SA 3.0.** These are derived works of it, so:

- **Attribution** — credit ChEMBL (European Bioinformatics Institute). The run
  logs record the retrieval and a curation signature; `runs/discover.log` names
  the UniProt accession and record counts.
- **Share-alike** — if you redistribute these files, or anything derived from
  them, that redistribution stays **CC BY-SA 3.0**. You cannot relicense them
  under MIT by virtue of their living in an MIT repository.

ChEMBL: <https://www.ebi.ac.uk/chembl/> · CC BY-SA 3.0:
<https://creativecommons.org/licenses/by-sa/3.0/>

Note what this does *not* cover: the generated candidate structures are novel
molecules, but they were produced by BRICS recombination **of ChEMBL compounds**,
so they are derived works and the share-alike term reaches them.

## Protein structures from the PDB — CC0, public domain

Coordinate files are fetched from RCSB at run time and are **not** redistributed
in this repository (`.cache/` is gitignored). PDB data is CC0 / public domain and
needs no permission, but the entries used should be cited:

| PDB ID | Role |
|---|---|
| **4FRS** | receptor for docking, enrichment, redocking and the pipeline |
| **7MYI**, **6UWP**, **6EQM**, **4L7G** | the cross-docking set |

Cite the structures themselves, not just this repository: a PDB entry has its own
depositors and primary publication. See <https://www.rcsb.org/> for each entry's
citation.

## Alert catalogues and SAscore — from RDKit, BSD-3-Clause

The PAINS and Brenk substructure catalogues and the synthetic-accessibility
(SAscore) fragment contributions are **shipped with RDKit** and used through it;
nothing is vendored here. RDKit is BSD-3-Clause.

One clarification, because this repository's docstrings mention PubChem: SAscore
was *calibrated against PubChem by its authors*. This pipeline does not retrieve
or redistribute any PubChem data. PubChem itself is public domain.

## In short

| What | Licence | If you redistribute |
|---|---|---|
| Code | MIT | keep the MIT notice |
| `runs/` artefacts | **CC BY-SA 3.0** (via ChEMBL) | attribute ChEMBL, **stay share-alike** |
| PDB coordinates | CC0 | not shipped here; cite the entries |
| RDKit catalogues | BSD-3-Clause | not vendored here |

If you are only using the code, MIT is all that applies. If you are using the
measurements, the share-alike term is the one to read.
